# Прототип переехал

Игра выросла в отдельный проект и живёт теперь здесь:

    ~/dev/naotmash

Называется **«Наотмашь»**, выложена на https://aka-gst.ru/worm/

Здесь остались файлы того состояния, в котором она отделилась, — как история
того, откуда она взялась. Разрабатывать её надо в `~/dev/naotmash`, иначе
правки разойдутся: живой файл там, а не тут.

К «Битве Стихий» прототип никогда не был подключён — общего кода у них нет,
только происхождение: концепт начинался как идея про дождевого червя, у
которого тело было одновременно здоровьем, оружием и риском.
