# Обвязка сайта-хоста

Копии файлов, которые живут в корне aka-gst.ru, а не в этом репозитории:

- `game-menu.css` — кнопка «НА ГЛАВНУЮ» поверх игры;
- `player-name.js` — диалог имени игрока и таблица результатов.

Игра ссылается на них как на `/game-menu.css` и `/player-name.js`. Локально
таких путей нет, и без копий предпросмотр врёт: кнопка «НА ГЛАВНУЮ» не
появляется, а на бою она висит в правом верхнем углу и однажды уже закрыла
имя противника с его полосой здоровья. Ошибку было не увидеть до выкладки.

`tools/serve.mjs` отдаёт эти файлы по корневым путям, поэтому локальный
предпросмотр совпадает с боевым. Файлы сюда только копируются — источник в
репозитории сайта; при расхождении обновлять копию, а не наоборот.
